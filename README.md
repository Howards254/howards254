## 🚀 Featured Projects

### 🌱 [GreenVerse — Maathai Innovation Catalyst](https://github.com/Howards254/maathai-innovation-catalyst)
> *A social environmental platform inspired by Wangari Maathai's Green Belt Movement*

A full-featured social network where users plant virtual and real trees, join campaigns, earn badges, and connect with eco-conscious communities worldwide.

- 🌐 **Live**: [maathai-innovation-catalyst.vercel.app](https://maathai-innovation-catalyst.vercel.app/)
- 🏗️ **Stack**: React 19 · TypeScript · Tailwind CSS v4 · Supabase · Vite
- ✨ **Features**: Stories & Reels, Direct Messaging, Tree Planting Campaigns, Gamification (Points & Badges), Leaderboards, Green Matchmaking, Real-time Notifications
- 🏆 Hackathon project — GreenBelt Movement / Wangari Maathai Foundation

---

### 🎮 [Gamer's Mint — NFT Marketplace on Hedera](https://github.com/Howards254/Hedera-Project-Gamer-NFT-MarketPlace)
> *Mint, list, and trade gaming NFTs on the Hedera blockchain*

A decentralized NFT marketplace built for the gaming community, integrating HashPack wallet and Hedera's fast, low-cost network.

- 🏗️ **Stack**: React 18 · Hedera SDK · HashConnect · Pinata/IPFS · Vite
- ✨ **Features**: HashPack Wallet Integration, NFT Minting & Listing, Hedera Testnet Transactions, IPFS Metadata Storage

---

### 💡 [MIC — Maathai Innovation Catalyst Platform](https://github.com/Howards254/MIC)
> *Connecting innovators, investors & job seekers to combat deforestation*

A platform where innovators submit sustainable timber-alternative projects, investors fund them, and job seekers find opportunities in the green economy.

- 🏗️ **Stack**: React 18 · React Router 7 · Tailwind CSS · Supabase · Vite
- ✨ **Features**: Role-based Access (User / Investor / Admin), Real-time Funding Progress, Job Board, Supabase Row Level Security

---

### 🤝 [ComradesHub](https://github.com/Howards254/comradeshub)
> *A social networking platform for comrades*

A PHP-powered social network with friend requests, real-time messaging, user discovery, and profile management.

- 🏗️ **Stack**: PHP · MySQL · HTML/CSS/JS
- ✨ **Features**: Friend System, Real-time Messaging (AJAX), User Discovery, Profile Management
